🫧 Burbujas

Las marcadas con «Ambiente» salen debajo del reloj, en este orden, solo cuando tienen algo que contar. En las pestañas se ponen con una «Fila de burbujas» (🗂️ Pantallas). Toca una para cambiar su título y su funcionamiento.
Cómo se escribe el funcionamiento 
render(ha, screen, config) → lo que se pinta

config (ajustes que se rellenan aquí, en «Ajustes» de la burbuja)
  config: { entity: { type: 'entity', domain: 'weather', label: 'Entidad' },
            showText: { type: 'bool', default: true } }      tipos: entity, device, text, number, bool, select
  watch: (config) => [config.entity]

ha (Home Assistant)
  ha.state(id)  ha.num(id)  ha.attr(id, 'x')  ha.name(id)  ha.fmt(id)  ha.entity(id)  ha.states
  ha.isOn(id)  ha.ok(id)  ha.minutesSince(id)
  ha.find('light.*', (s, id) => …)  ha.count('light.*', 'on')
  ha.info(id) → { platform, device, deviceId, area, areaId, key }   de qué integración y aparato es
  ha.devices('bambu_lab') → [{ id, name, area, entities }]   aparatos de una integración
  ha.number(21.46) → '21,5'   ha.duration(4800) → '1 h 20 min'
  ha.call('light.turn_off', { entity_id: 'light.x' })   solo dentro de onTap

screen (la pantalla)
  screen.place → 'ambient' | 'home' | 'card'      screen.brightness  screen.on  screen.night  screen.ambient
  screen.alarms  screen.nextAlarm() → { name, when, text }      screen.light (sensor de luz, futuro)
  screen.visible(id)  screen.go('media')  screen.nowPlaying(id)  screen.now()

Burbuja → { icon, text, color, textColor, iconEnd, iconEndColor, progress, go, onTap }  (o una lista, o null)
Tarjeta → [ { title }, { text, size: 'big'|'small' }, { tiles: [ids] },
            { stats: [{ icon, value, label }] }, { chips: [burbujas] },
            { button: { text, icon, go, onTap } } ]
onTap: (ha, screen) => ha.call('light.toggle', { entity_id: 'light.salon' })
go = 'home' | 'rooms' | 'sensors' | 'media' | 'printers' | 'scooter' | 'settings' | id de pestaña
