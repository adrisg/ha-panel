🔒 Panel Hogar

Panel Hogar Raspberry Pi panel configuration

🧪 Simulation mode (computer). Brightness, screen off and the network are simulated: you can try everything without changing anything on this computer.

🧩 Components

What goes in the tabs (buttons, cards, weather…). Each one is code: it declares its fields, what it watches and what it draws. Place them in 🗂️ Tabs.
New component

🗂️ Panel tabs

Each tab of the side bar with its cards, laid out as on the panel. Tap one to change it.

🎵 Ambient mode player

The first one on the list that is playing wins; if none is playing, the first paused one, otherwise the first one.

🖼️ Ambient mode photos

🫧 Bubbles

Those marked “Ambient” appear under the clock, in this order, only when they have something to tell. In tabs, add them with a “Bubble row” (🗂️ Tabs). Tap one to change its title and how it works.
How to write how it works 
render(ha, screen, config) → what it paints

config (settings filled in here, in the bubble “Settings”)
  config: { entity: { type: 'entity', domain: 'weather', label: 'Entity' },
            showText: { type: 'bool', default: true } }      kinds: entity, device, text, number, bool, select
  watch: (config) => [config.entity]

ha (Home Assistant)
  ha.state(id)  ha.num(id)  ha.attr(id, 'x')  ha.name(id)  ha.fmt(id)  ha.entity(id)  ha.states
  ha.isOn(id)  ha.ok(id)  ha.minutesSince(id)
  ha.find('light.*', (s, id) => …)  ha.count('light.*', 'on')
  ha.info(id) → { platform, device, deviceId, area, areaId, key }   which integration and device it belongs to
  ha.devices('bambu_lab') → [{ id, name, area, entities }]   devices of an integration
  ha.number(21.46) → '21.5'   ha.duration(4800) → '1 h 20 min'
  ha.call('light.turn_off', { entity_id: 'light.x' })   only inside onTap

screen (the screen)
  screen.place → 'ambient' | 'home' | 'card'      screen.brightness  screen.on  screen.night  screen.ambient
  screen.alarms  screen.nextAlarm() → { name, when, text }      screen.light (light sensor, future)
  screen.visible(id)  screen.go('media')  screen.nowPlaying(id)  screen.now()

Bubble → { icon, text, color, textColor, iconEnd, iconEndColor, progress, go, onTap }  (or a list, or null)
Card   → [ { title }, { text, size: 'big'|'small' }, { tiles: [ids] },
            { stats: [{ icon, value, label }] }, { chips: [bubbles] },
            { button: { text, icon, go, onTap } } ]
onTap: (ha, screen) => ha.call('light.toggle', { entity_id: 'light.living_room' })
go = 'home' | 'rooms' | 'sensors' | 'media' | 'printers' | 'scooter' | 'settings' | tab id
